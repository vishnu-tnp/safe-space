# Safe-Space 🌿

> **GenAI Recovery & Caregiver Support Hub** — A low-cognitive-load, multi-modal web application designed to support individuals in recovery (Patients) and their Caregivers.

Safe-Space emphasizes zero-typing check-ins, interactive tactile grounding exercises (4-7-8 breathing, 5-4-3-2-1 sensory grounding, EMDR bilateral tracing, and a Zen sandbox), positive GenAI reinforcement, and real-time actionable caregiver guidance to reduce distress during vulnerable moments and foster supportive communication.

---

## ✨ Features

### 🧘 Patient Portal
- **Zero-Typing Check-in:** Oversized interactive pickers and quick-tap trigger tags (Stress, Sleep, Loneliness, Conflict, Craving) for effortless mood logging.
- **Interactive Grounding Suite:**
  - 🌬️ **4-7-8 Breathing Visualizer:** Interactive pulsing circle with rhythmic visual audio timing.
  - 🖐️ **5-4-3-2-1 Sensory Grounding:** Step-by-step interactive sensory game with empathetic AI feedback.
  - ♾️ **EMDR Bilateral Pattern Tracing:** Interactive figure-8 finger tracing with dual visual cues.
  - 🫧 **Zen Sandbox:** Tactile bubble-pop distraction tool for craving management.
- **Daily Micro-Wins & Streak Tracker:** Visual progress indicators and positive reinforcement.
- **One-Tap Emergency SOS:** Instant caregiver notification with crisis support links.

### 🛡️ Caregiver Portal
- **Real-Time Status Feed:** Live view of patient check-ins and mood progression.
- **GenAI Co-Pilot Scripting:** Context-aware AI-suggested empathetic conversation scripts tailored to patient triggers.
- **Communication Guardrails:** Actionable "What TO Say" and "What NOT to Say" guidance to prevent triggering phrases.
- **Psychoeducation Hub:** Bite-sized addiction neuroscience and self-care resources for caregivers.

## 🛠️ Tech Stack

- **Framework:** React 19, TypeScript, Vite
- **Styling & UI:** Tailwind CSS v4, Lucide React Icons
- **State Management:** React Context API (`AppContext.tsx`)
- **AI Integration:** Google Gemini API (`Gemini 1.5 Flash` / `Gemini 3.1 Flash`)
- **Linting:** Oxlint

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vishnu-tnp/safe-space.git
   cd safe-space
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
